# Ronda 1 — Definición del plugin

24 preguntas en 6 bloques, para cerrar las decisiones de producto y arquitectura antes de escribir código.

## Cómo responder

1. Doble clic en `index.html`. Abre en el navegador desde `file://`, sin servidor ni conexión.
2. Cada pregunta tiene tres opciones; la primera es la recomendada y explica por qué. Si ninguna cierra, escribí la tuya en el campo de texto: vale más que elegir la menos mala.
3. Las respuestas se guardan solas en el navegador (`localStorage`), así que podés cerrar y seguir después. Es por navegador y por máquina.
4. Al terminar, **Descargar** deja `maps-to-3dmax-ronda1.json` al lado de este README. **Copiar JSON** hace lo mismo al portapapeles.
5. Pasame ese JSON.

Las cuatro preguntas marcadas **CRÍTICA** (AA1, BB1, CC1, DD1) son las que más código arrastran. Si vas con poco tiempo, respondé esas cuatro y mandá el JSON incompleto — el campo `sin_responder` lista lo que quedó pendiente.

## Convención de rondas

Cada ronda vive en su propia carpeta y deja dos archivos:

```
docs/preguntas/ronda-N/index.html                  las preguntas
docs/preguntas/ronda-N/maps-to-3dmax-rondaN.json   tus respuestas
```

Mismo formato que `docs/ronda*` en LibrerIA3D.
